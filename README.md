# HackNow AI-Poligon — boshlang'ich notebook'lar

Sun'iy intellekt xavfsizligi bo'yicha amaliy lablar uchun boshlang'ich notebook'lar. Har biri bitta labga tegishli:
vazifani tushuntiradi, labga ulanishni tayyorlaydi va topshiriqlarni beradi. Yechimlar bu yerda yo'q — ularni
o'zingiz yozasiz.

Lablarning o'zi [platform.hacknow.uz](https://platform.hacknow.uz) da: hujum kodi sizning notebook'ingizda ishlaydi,
natijani esa server tekshiradi va to'g'ri yechimga flag beradi.

## Qanday ishlatiladi

1. Platformada kerakli lab challenge'ini oching.
2. Pastdagi ro'yxatdan shu labning notebook'ini Google Colab yoki Kaggle'da oching.
3. Platformadagi lab oynasidan **Token**ni nusxalab, notebook'ning birinchi kod katagidagi `TOKEN` ichiga qo'ying.
   Token faqat sizga tegishli va bir necha soatdan keyin eskiradi.
4. Kataklarni tartib bilan ishga tushiring va topshiriqlarni bajaring. Yechim to'g'ri bo'lsa notebook flag'ni
   chiqaradi — uni platformadagi challenge sahifasida yuboring.

Kaggle'da notebook ochilgach, o'ng paneldagi «Session options» ichida Internet yoqilgan bo'lishi kerak.
Platformadagi lab oynasida tokeningiz oldindan qo'yilgan tayyor notebook'ni yuklab olish tugmasi ham bor.
